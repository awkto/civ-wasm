Game files and saves

You need your own copy of the original game files. Choose the game's folder, a .zip of it, or drop either here. The files stay in this browser and are never uploaded. For the Windows version's map art, add civdata4.rsc from Civilization for Windows (or its folder or .zip) the same way.

A save file is a .zip from Download, or a CIVILn.SVE with its .MAP. Forget game files removes the game's files from this browser, not your saves.

About

Game logic from civd, a reverse-engineered reconstruction of the DOS source; platform layer from reciv; compiled to WebAssembly. Saved games are kept in this browser. Mouse and keyboard work as in the original.
